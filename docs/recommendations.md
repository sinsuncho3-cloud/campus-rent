# 활동 추천·키워드 확장

기존 네 가지 목적을 유지하고 영상 콘텐츠 촬영·면접 연습·과제·학습을 추가했습니다. 목적·키워드·제외 표현·장비 구성은 Oracle의 USE_PURPOSE, PURPOSE_KEYWORD, PURPOSE_EQUIPMENT_RULE에서 읽습니다. 정해진 단어 몇 개만 비교하던 브라우저 코드를 교체했습니다.

| 목적 | 주요 인식 표현 |
| --- | --- |
| 과제 영상 촬영 | 과제 영상·촬영·녹화, 수업 영상, 조별 영상, 팀플 영상, 영상 과제·보고서·리포트·레포트, 캡스톤 영상, 졸업 작품 촬영, 수행평가 영상, 단편 영화, 다큐멘터리 |
| 과제·학습 | 과제 작성, 레포트·리포트·보고서, 논문·졸업 논문, 자료·문헌 조사, 코딩·프로그래밍 과제, 프로젝트 작업, 캡스톤 작업, 실험 보고서, 중간·기말고사, 자격증 준비, 문제 풀이, 독서·코딩 스터디, 자기소개서·자소서 |

정확한 초기 목록은 `db/oracle11g/recommendation-seed.json`입니다. 띄어쓰기·영문 대소문자를 정규화하며 PT 같은 영문 약어는 단어 경계를 확인합니다. 인원은 별도로 검사하고 범위·음수·소수·서로 다른 숫자를 단일 확정 인원으로 처리하지 않습니다.

## 문맥에 따른 구분

- ‘과제’만 입력하면 학습·회의·영상 과제 중 선택하도록 합니다. 발표·회의 등 복수 목적은 선택지를 유지합니다.
- 과제의 영상 제작과 일반 콘텐츠 촬영을 구분합니다. 보고서·자료 조사·시험 공부에는 촬영 장비를 자동 추천하지 않습니다.
- 면접 연습은 조용한 공간을 우선합니다. 자기소개 녹화·촬영 요청이 있을 때만 카메라·마이크를 선택 장비로 추가합니다. PT 면접을 단순 발표로 오인하지 않습니다.
- 유튜브 시청·영상 감상·편집만·촬영 없이 같은 입력은 촬영 추천을 억제합니다. ‘카메라 없이’·‘마이크 없이’는 해당 장비만 제외합니다.
- 과제 유형·모호한 문장의 의미를 모두 이해하는 AI 방식은 아닙니다. 명시적 사전과 문맥 규칙이며 사용자는 목적·일정·인원을 확인한 뒤 제출합니다.

## DB·시설 반영

`12_recommendations.sql`은 기존 목적·키워드·장비 규칙을 지우지 않는 재실행 가능한 추가 DML입니다. 기존 테이블·SQ_ 시퀀스 이름을 유지하고 새 객체는 생성하지 않습니다. `tools/generate-recommendation-sql.ps1`로 초기 JSON에서 생성합니다. 오류 시 전체 롤백하는 트랜잭션으로 적용하며 앱 시작·기존 install_dev.sql에서 자동 실행하지 않습니다. 현재 팀 DB에는 적용했습니다.

새 영상 목적은 원래 DEMO-STUDIO01/02, 면접·학습 목적은 원래 DEMO-ROOM01/02·DEMO-STUDY01에만 시연 허용 용도로 연결했습니다. IS_DEMO_YN과 코드가 모두 일치해야 하며 실제 학교 시설이나 다른 시험 자산에 일괄 복사하지 않습니다. 시설 변경 버전도 갱신했습니다. 실제 시설은 `/admin/facilities`에서 확인 후 허용 용도를 추가해야 추천·신청할 수 있습니다. 새 목적의 시연 시설 연결은 실제 학교 운영 허가를 의미하지 않습니다.

목적별 장비는 사용 중인 품목의 설정 규칙을 따릅니다. 중지·점검·대여 불가 장비는 추천 후보에서 제외하고 해당 품목의 자산이 없어도 화면 오류를 내지 않습니다. 추천이 예약 확보를 의미하지 않으며 최종 신청·승인에서 서버가 허용 목적·시간·정원을 재검사합니다. 입력한 활동 내용과 선택 경로는 기존대로 신청에 저장합니다.

## 관리·검증

관리자로 `/admin/recommendations`에서 키워드를 추가·수정·해제할 수 있습니다. 목적별 포함/제외, 전체 일치/포함, 우선순위를 설정하고 조회 화면에서 검색합니다. 변경은 Oracle에 저장되며 다른 사용자는 다음 새 조회·새로고침 때 반영됩니다. 오래된 창의 수정은 기존 값 비교로 차단하고 삭제 대신 해제합니다. 문맥 규칙은 키워드와 별도로 적용합니다. 새 목적 정의·장비 규칙 자체를 편집하는 UI는 이번 범위에 포함하지 않습니다.

시험: `RecommendationOracleTest`와 `tools/check-ui.ps1 -Recommendations`. 신규 목적·키워드와 허용 시설의 신청, 관리자 권한·수정 충돌·키워드 해제, 예문·부정 표현·인원·화면 연결을 확인합니다. 브라우저에서 추가한 시험 키워드는 종료 시 해제하고 기록을 남깁니다.
