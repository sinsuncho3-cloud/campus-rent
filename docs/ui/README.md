# CampusRent 화면 구현

## 기준 자료와 구조

- 개발 스펙: [루트 README](../../README.md), [프로젝트 계획서](../New-Era_PROJECT.md)
- 원본: `Implement CampusRent Home Screen (복사).zip`의 React·TypeScript 코드, SVG 14개, 로컬 폰트 3개
- 구현: `src/main/resources/templates/index.html`, `src/main/resources/static/`의 HTML·CSS·JavaScript 모듈

최종 프런트엔드 스펙에 맞게 React·Tailwind 런타임 없이 전환했습니다. 원본 ZIP은 변경하지 않았고 `.gitignore`에 따라 Git에서 제외됩니다. 압축 해제본, Java 빌드, Chrome 검증 결과와 캡처는 `.work/`에 저장됩니다.

## 구현 화면

| 경로 | 동작 |
| --- | --- |
| `/` | 원본 홈 구성, 활동 입력·키워드, 장비·시설 진입, 활동별 예시, 예약 절차 |
| `/equipment` | 장비 7개 검색·분류, 수령·반납 일정, 사양·구성품, 이용 가능 여부 |
| `/facilities` | 시설 5개 검색·분류, 일정·인원·용도, 수용 인원·운영 시간 확인 |
| `/purpose` | 활동·참여 인원 분석, 모호한 목적 확인, 규칙 기반 추천과 이유 |
| 공통 선택 목록 | 항목별 일정 보존·수정·제거, 인증 후 별도 최종 신청 |
| 상세 팝업 | 사양·관리번호·구성품, 같은 일정의 대체 자원, 같은 자원의 다른 일정 |
| `/records`, `/history` | 본인의 진행·과거 신청, 승인 전 취소, 반납 요청, 처리 사유 |
| `/admin` | 개별 승인·거절, 구성품 출고 확인, 반납·보류·추가 반환·점검, 시설 시작·종료 |

홈의 레이아웃·문구·색상·아이콘과 자원 이름·사양·구성품은 제공된 ZIP을 기준으로 옮겼습니다. 모바일에서는 메뉴와 카드가 줄바꿈되며 선택 목록은 검색 결과 아래에 표시됩니다. Figma 이후 수정 사항은 자동 동기화되지 않습니다.

## 시연 동작과 연동 범위

- 준비된 계정과 브라우저 메모리 기반 시연 회원가입을 제공합니다. 시연 계정은 루트 README와 로그인 팝업에 안내합니다.
- 비밀번호는 메모리의 해시로 비교하며 비밀번호·인증 정보를 브라우저 저장소에 보존하지 않습니다. 로그인과 신규 시연 계정은 새로고침하면 초기화됩니다.
- 선택 목록은 탭별 `sessionStorage`, 신청·검수·점검은 `IndexedDB`에 보존됩니다. 신청 내역에는 시연 신청자의 ID와 이름이 기록됩니다.
- 신청은 승인 대기 상태로 저장됩니다. 관리자 승인 시 이용 조건과 최신 예약을 다시 검사합니다. 같은 저장소의 쓰기 트랜잭션과 버전 확인으로 다중 탭 중복 승인·오래된 상태 변경을 방지합니다.
- 출고 시 구성품 기준을 복사합니다. 반납은 이번 수량과 누적 수량을 구분하며, 초과 반환·구성품 미반납 완료를 차단합니다. 부족분은 보류 후 추가 반환할 수 있습니다.
- 실제 서버 인증·권한, 학교 정책, Oracle·Spring Boot 연동, 배포는 구현하지 않았습니다. 브라우저의 시연 권한 검사는 실제 서버 보안을 대신하지 않습니다.
- 장비 기본 정보 관리(F08), 대체 관계 편집(F17 관리 부분), 시설 운영 기준 관리(F21), 추천 기준 편집은 후속 화면 범위입니다.

## 실행

JDK 8 이상의 `java`와 `javac`를 PATH에 등록하고 루트에서 실행합니다.

```powershell
.\preview.cmd
```

[로컬 미리보기](http://127.0.0.1:8080/)를 엽니다. 서버는 로컬 PC의 `127.0.0.1`에서 실행되며 종료는 `Ctrl+C`입니다. 포트를 바꾸려면 미리보기 빌드 후 `java -cp .work/preview PreviewServer 8081 .`로 실행합니다. 이 서버는 정적 화면만 제공하며 Thymeleaf 엔진을 실행하지 않습니다.

## 검증

미리보기 서버 실행 후 PowerShell에서 실행합니다. Chrome이 기본 경로에 없다면 `CHROME_PATH` 환경변수를 설정하세요. Node.js 설치는 필요하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/check-ui.ps1
```

검증은 사용자 브라우저와 분리된 임시 Chrome 프로필에서 실행하고 해당 브라우저를 종료합니다. 결과는 `.work/browser-check-result.txt`, 홈 캡처는 `.work/home-desktop.png`·`.work/home-mobile.png`에 저장합니다.

2026-10-28 검증: Chrome 검사 34개 통과. 자원·추천·대체 조회, 날짜·인원 검증, 신청 소유권·관리자 역할, 동시 중복 승인, 버전 충돌, 출고·반납, 실제 홈·검색·로그인·신청 조작과 1200px·390px 화면 4종의 가로 넘침을 확인했습니다. PC·모바일 홈 캡처도 시각 확인했습니다. 서버·DB 통합 시험 결과는 아닙니다.
